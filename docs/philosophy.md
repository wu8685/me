# ME 理念

> 三层知识飞轮 + 自由 WikiLink 交叉引用

## 设计原则

**ME** 遵循以下设计原则：

1. **零基础设施** - 只需 Git + Markdown + Claude Code 或 Codex，无需数据库或向量存储
2. **三层知识飞轮** - Raw → Practices → Cognition 知识流动模型
3. **自由交叉引用** - WikiLink 可跨越任何层级边界
4. **CLI 友好** - 所有操作可通过命令行自动化
5. **可复用** - 通用框架，与具体领域知识库分离


## 为什么是三层？

| 层级 | 作用 | 例子 |
|------|------|------|
| **Raw** | 输入层：未过滤的信息、灵感、引用 | 调研笔记、文章摘录、观察记录 |
| **Practices** | 转化层：经过实践验证的可复用方法 | 设计模式、工作流、代码片段 |
| **Cognition** | 输出层：形成稳定认知，指导新实践 | 原则、世界观、决策框架 |

更多层级会增加复杂度，但收益递减。三层是经过验证的最小集合。

## 目录即生命周期

ME **不使用** frontmatter 的 `status:` 或 `lifecycle:` 字段。

**规则：** 文件所在的目录就是它的生命周期阶段。

- `raw/article.md` = 摄入阶段
- `practices/pattern.md` = 实践阶段
- `cognition/principle.md` = 认知阶段

移动文件 = 生命周期转换。这种方式：
- **简单** - 无需维护状态字段
- **直观** - 目录结构即状态
- **灵活** - 支持任意工作流

## 与 Obsidian 的关系

ME 创建的 vault 是**标准 Obsidian vault**：

- ✅ 可用 Obsidian 打开、编辑、图形化查看
- ✅ 兼容 Obsidian 插件
- ✅ Obsidian CLI 可用时，ME 使用增强模式
- ✅ 纯文本格式，任何编辑器可用

**ME != Obsidian 替代品**

ME 是命令行工具集，补充 Obsidian 的弱项：
- 批量操作（自动链接、链接检查）
- CLI 自动化（CI/CD 集成）
- AI 辅助（Claude Code / Codex 原生集成）

## 与 knowledge-base 的关系

| 组件 | 仓库 | 作用 |
|------|------|------|
| **ME** | [github.com/wu8685/me](https://github.com/wu8685/me) | 知识管理运行时 —— 提供"怎么用"的工具链 |
| **knowledge-base** | `github.com/wu8685/docs` | 具体领域知识 —— 提供"有什么"的内容 |

**类比**：knowledge-base = 应用程序（数据和业务逻辑），ME = 运行时框架（基础能力）
